# PR 27 isolated UX preview

Preview: https://pr27-gameverse-host-staging.gameverse-environment.workers.dev/account

Implementation `c26b5ace32707a0828783929c372994a4e61c740`; preview URL configuration `d0f52fb`.

This preview runs the actual #26/#27 account, manager and hosted-player code before merge. No synthetic login bypass or provider fixtures are deployed. Sign in with an invited phone number. Account/job Durable Object namespaces are preview-specific; artifacts use `gameverse-artifacts-pr27`. Account identity salt, encryption key and admin token are generated for the preview. The owner explicitly approved using existing team Daytona and Twilio sign-in credentials in this isolated deployment. No OpenAI/Claude user key was copied in; add a key manually if testing hosted voice.

The manager and voice broker trust this exact HTTPS origin in addition to the live origin. Other workers.dev hosts, lookalikes, credential-bearing URLs and unapproved HTTP origins are rejected. The Mac manager uses `GAMEVERSE_MANAGER_URL` pointing at this preview and its own `GAMEVERSE_MANAGER_DIR`, preserving separate pairing from the live installation. Start with the repo manager command and a private env file containing the team Daytona key. Discovery remains a deliberate **Check for dev app** action; enter the terminal code and click **Connect**. Pairing survives restarts. Run lifecycle check is a bounded model-free job; arbitrary coding/personal Codex remains gated.

Preview-only hosted policy: 120 seconds per job, 30 model attempts per root, one active job per account, two platform jobs and three admitted jobs per rolling day/account. These are small trial allowances, not production limits or an SLA. Voice requires a suitable account API key and a deliberate audio submission. No model calls were performed while deploying this preview.

All application edits, regression verification, build and Worker bundling ran in private Daytona sandbox `37dadd1b-29a9-46ab-b8e3-e52cb979daa2` (2 CPU / 4 GiB / 8 GiB; Node 25.9.0; 60-minute hard TTL). The affected manager/hosted suite passed 70 tests in 17.500 seconds, including exact-preview trust and rejected-host cases. A matched clean-dist pair with installed dependencies measured 60.5 ms before and 66.1 ms after; a single small pair does not establish an SLA. Existing browser/hosting suites passed in the preceding PR review; they were not rerun because application control and provider behavior were unchanged. No new dependencies or routine CI jobs.

The Mac uploaded the already-built Worker with `no_bundle` and public assets, plus approved secrets, using Cloudflare's preview deployment command. No production code was deployed. Preview deployment `2695f2a1-4473-4dc9-b4e4-62347fc0f130`, preview ID `a2bfc024164548e981b40de0ac6c9b1c`, created isolated namespaces through migration v5. Preview URL serving was enabled separately while preserving live workers.dev serving. The original live deployment `a446f1e8-469f-4ea6-8dd3-e221ff5a6936` remained active, with no manager binding in production.

A real no-model fetch from Daytona to the preview health endpoint returned HTTP 200 in 360 ms. The live-host egress failure therefore does not block this preview hostname. This alone is not full separate-worker/provider acceptance: ASR/Decisions access, actual voice-worker execution, takeover and Stop/handback still require a live account-key run. The signed-in account UI was reached in the developer's Chrome session. Private deployment receipts and images are retained outside Git; no phone numbers, credentials, cookies, pairing codes or launch capabilities belong in this document.
