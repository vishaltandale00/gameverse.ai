# Triage labels

The skills speak in terms of five canonical triage roles. Use this mapping when applying those roles in the issue tracker.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | More information needed |
| `ready-for-agent` | `ready-for-agent` | Fully specified for an agent |
| `ready-for-human` | `ready-for-human` | Human implementation needed |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role, use the corresponding tracker label. Edit the tracker-label column if the repository's label vocabulary changes.
