# MegaMan Zero: source command-response prefab

[delivery.json](delivery.json) supplies one coherent, narrowly named prefab: **Direction command → facing and horizontal position**. [prefab-allowlist.json](prefab-allowlist.json) pins its actual graph. The source-core-loop map preserves the surrounding input producer, mode admission, terrain/contact, secondary action and postdispatch service order; the horizontal routine is never presented as the whole controller or core game.

The graph passed real `assembly.py` Composer/lowering admission with `binding_valid_obligations_unproven`. Its five scalar ports and command collection share one actor module identity. Inputs are current source command storage/index, horizontal native magnitude, current position and facing state; outputs bind updated position, facing selector and packed flags. The explicit default supplies command byte8, index0 and native magnitude512. Its expected positive512 coordinate response is source-derived arithmetic, not a new runtime execution result. No pixel scale, timestep, complete original initialization or live-game legal magnitude range is claimed.

A single source routine is a useful command-response transaction, as allowed by the canonical delivery contract. It supplies the control/fighter-control facets through **one module instance**; it does not supply hardware input sampling, terrain, gravity, landing, attacks, damage or defeat. Runtime qualification remains false and all full-game obligations remain visible.

The smallest input gap was actively attempted rather than restated. Source producer `0x0801b29c` advances the same actor ring modulo64 and maps effective input through `0x0801b374`/`0x0801b340` before writing ring/edge state. The automatic producer fails at `0x0801b374`: **pointer-like ROM literal escaped as scalar**. That selector returns either an actor-owned mapping or an immutable ROM control-table view. Its return must preserve pointer identity across the call. The mapper now automatically lifts under the current compiler, but it is unpublished and unqualified; it is not used in this prefab. Exact reproducible attempts and source hashes are retained privately and were sent to the compiler owner.

Actual current Composer behavior preserves bound write-only fields on untaken conditional stores. An initial direct-Composer comparison omitted that assembly overlay and produced a different statement hash; the failed comparison is retained. The final comparison uses the exact current overlay and matches the real assembly receipt. No source proof files were changed.

Only narrow graph/pin checks ran. The delivery check found no installed JSON Schema library, so full schema validation is unavailable; required top-level fields, exact graph/receipt hashes, real admission status and matching Composer/lowering were checked. No dependency was installed. Timings and failures are retained in the delivery and private receipts. No JVM, new native run, generated game, ROM, demo or central edit was made.
