# MegaMan Zero: source world installation and real inactive-plane consumers

The actual world installer and plane ownership are now pinned. Original `0x080060b4` installs **12 plane records** through `0x08005288` from own-ROM relative asset triples and packed section variants. Each triple is relative to its own record, not one global bank base. Source `0x080061f8` selects the descriptor and builds the active cache with `0x08006be8` before its source world/frame callbacks. Inactive-plane queries instead borrow the installed immutable layout, tile bank and collision metadata.

A small **original-ROM-only** fixture executed the source installer, then real section1 empty/solid/slope queries through raw tile/attribute samplers and both actual directional callback bodies. All12 installed references matched the source ROM calculations; four real cells returned tile IDs **0,1046,1131,1132**, attributes **0,1,2,3**, and directional corrections **(0,0),(-2049,22528),(0,0),(-2049,14336)**. Every call returned with ABI preserved, and there were **zero invalid-memory diagnostics**. This is genuine original map data and source services, not an out-of-map or empty-terrain stub. It is **not L1 parity** or a full actor/controller witness.

The first intended empty cell used source grid sentinelF1. That initial fixture is retained separately; the corrected empty point uses actual grid1 and tile0. Only this failed coordinate selection justified the narrow rerun. The full actor parent was not rerun. Earlier producer parity was reused.

[world-view-contract.json](world-view-contract.json) pins immutable data, source functions and ownership. It records source layout stride/width/height and origin,150-cell chunks, byte metadata and packed configuration. The active cache width is header columns×15 cells; its height derives from header rows×10. No persisted RAM height field is claimed. Its source arena can extend through `0x02021640`; the former synthetic actor base `0x02010000` lies inside that arena and must not be reused in a valid active-map actor fixture.

A bounded automatic `0x080064ac` attempt used the real readonly plane1 contract and a source coordinate window containing the solid/slope witnesses. It failed at source op34 / `0x08006514`: the compiler widens the section descriptor index to0..15 and encounters a trailing zero outside the real12-entry table. Exact source lookup data proves section1: X lookup is always64, Y lookup is1or2, and both corresponding grid bytes equal1. The correct repair is finite immutable-ROM value propagation before pointer classification, not weakening pointer validation. The minimized reproducer and exact table/SSA diagnostic were sent once to the compiler owner.

Corrected original oracle compile/run took **0.053088584 / 0.075009666 s**; source installation used **660 instructions**. The automatic sampler attempt took **0.007931459 s**. Queue and interactive total are unavailable.
