# Crash: phase-latched transition closure (partial)

This packet maps one causal slice from the game's own ROM: trigger → one-shot phase request → table-driven application → phase/latch rearm. It does **not** identify a complete named move, recover the controller, or qualify a portable component. Mario remains the active depth priority; all games remain partial.

`packet.json` pins the exact queue item, ROM, function export, per-function pseudo-C oracle hashes and existing HighFunction exports. Manual/pseudo-C was read only as an analysis oracle; only pinned own-ROM HighFunction is eligible for future automatic lifting.

- **Producer `0x080151c8`:** nonzero controller latch `+0x23` returns immediately. Otherwise latch becomes 1; phase `+0x22` maps 0/1→request 24, 2→25, 3/4→26. Recognized phases set `mode32=0`, `dirty30=1`; all phases OR actor `flags0d` with 1 and clear controller `gate34`. Unrecognized phases keep the previous request/dirty state: do not silently restrict or clamp them.
- **Triggers:** `0x0801283c`, call `0x080128f6`, reaches producer for controller state 14, nonzero phase and positive actor scalar `+0x64`, subject to earlier priority handling. `0x08013eac`, call `0x08013eda`, also triggers when actor `contact68==0` and phase is nonzero.
- **Consumer `0x08012af4`:** dirty `+0x30==1` selects the second mapping field using request `+0x28` and controller `+4`; it reads a 12-byte triple at `0x0816ae44 + 12*index`, calls an apply method through descriptor `+0x30/+0x34` (or variant `+0x40/+0x44`), then clears dirty. `0x08012420` calls this consumer at `0x080125dc` after state-method dispatch. Actual target/scheduler identities are pending.
- **Rearm:** `0x08015038` evolves phase/cycle and clears latch; `0x08013eac` has a pressed-input/contact branch that also clears it. Repeated producer calls without rearm are intentionally idempotent.

A useful alias dependency is now explicit: held input at `0x030007e0` and pressed edges at `0x030007e2` share a packed 32-bit view. `0x080007ac` stores two **halfwords**, pressed before held; consumer word loads therefore expose pressed bits as `0x10000/0x20000`. These are not independent missing input writers. Retain controller/actor interior references and possible global-actor aliases in the same backing storage.

The mandatory method trampolines are directly visible in ROM bytes: `0x0803a8c0` is `BX r2; NOP`, and `0x0803a8c4` is `BX r3; NOP`. Their descriptor-supplied targets remain unresolved. Apparent indirect calls through **LR** at function tails are return/ABI recovery candidates, distinct from these true dynamic methods; do not stub them as optional effects. The payload domains, descriptor initializers, actor alias relationships, units and gameplay reachability also block an executable closure. This packet inventories the causal boundary; it does not claim that boundary has been lifted.
