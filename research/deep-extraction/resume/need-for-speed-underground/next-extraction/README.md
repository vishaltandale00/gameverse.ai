# NFS identity subsystem: actual extraction advance

[system.json](system.json) and [l2-contract.json](l2-contract.json) provide the source-backed identity editor/profile acceptance subsystem for ontology ingestion. [result.json](result.json) pins private executable artifacts and receipts. All-game and subsystem status remain partial.

Actual automatic lifting of eight cohesive roots produced one dependency: `0x08001790`, the scene request helper. Its serialized own-ROM L1 preserves the source order: sentinel byte `255`, requested scene byte, signed fade `-16`, auxiliary word zero. Generated lowering passed **1,024 native parity vectors / 21,504 instructions**, including ABI checks. This uses synthetic boundary/random fields, not gameplay traces. It qualifies the helper only. L1 SHA256: `877b4c026656c6dfdd3b0af660bbe539747b32122f0e29325e58e9e698d4d8c8`. Native receipt lives at `local/ir/fleet-next/need-for-speed-underground/attempt01/08001790/receipt.json`.

New source closure identifies the previously missing fade producer: `0x08000c0c`. After display services and a tick-counter increment, it advances signed fade one toward zero, then advances another countdown and calls input sampling. The editor's acceptance delay therefore depends on this controller, not an immediate fade reset. Source timing helpers stop/read timer 2 (halfword control `0x0400010a`, counter `0x04000108`); actual specialized lifts with source constant `r0=2` still block on hardware pointers. Their receipts are retained.

Current failures are executable attempts, not predictions: input sampling rejects a KEYINPUT hardware pointer; drawing and copy dependencies need typed loop-carried pointer support; audio dependencies need a bounded record collection; acceptance reaches unsupported CALLOTHER through its dependency chain. Full traces, dependency edges, source/L0/backend hashes and timings are retained in the private automatic-attempt receipt. These were sent to the compiler worker. No decompiler C entered compilation, no shared compiler/catalog changes, and no generated games were made. Exact dependencies were already cached; no JVM/export permit was needed.

Automatic lift attempts took **0.047738 s**; native qualification **0.237143 s** including nested build/link/oracle/parity stages; first fade-root attempt **0.007448 s**. Timer attempts separately measured **0.001489 s** and **0.000372 s**. Queue and complete interactive-analysis duration are unavailable. Stage timestamps are comparable only within their reported environment/configuration; no before/after implementation-performance claim is made.
