# Prince of Persia prefab delivery

**No primary prefab is addable from the current published Prince package set.** Product review requires an actual hazard/protection/history decision consumer; initializer/reset and isolated gate-query cards stay internal support. `prefab-allowlist.json` is intentionally empty.

`delivery.json` reconstructs one canonical engine/world context with actor, sprite and history references. It maps original controls and terrain probing, accepted resource loss, repeated-hit protection, timer/drain ordering, history restoration and the missing checkpoint/terminal continuation boundary. These source phases are not recovered executable controllers.

`clock-initialize.assembly.json` is an actual Composer-validated **internal support transaction**, not a primary game-building card. The supplied EngineInitialization event corresponds to original startup `0808fc70 → 080914c0`. Outputs are a reset pulse word and cleared stop byte; adjacent opaque bytes remain preserved. Validation took **0.002586708 s**. It neither advances a timer nor supplies a useful hazard decision by itself.

`world-gate-query.assembly.json` attempts actual masked-gate result capture with default mask 1. Its initial validation failed in **0.000766417 s** because the published package lacks an explicit return semantic contract. The additive return metadata was centrally published in backend wave07 with unchanged ROM/HighFunction/native proof. This query alone still does not close its source hazard consumer; no new query proof was run after that metadata-only update.

The smallest meaningful decision frontier, original predicate `080133b4`, was attempted once against the current compiler with the current published gate dependency. It failed in **0.015911375 s**:

> unresolved indirect call: stack-derived call argument needs no-escape proof

The exact L0, gate package and compiler hashes and traceback are retained in `local/ir/fleet-next/prince-of-persia-the-sands-of-time/prefab-pass/hazard-predicate.blocker.json` and sent to the compiler owner. No callback, alias, argument or terrain behavior was replaced with authored logic.

The earlier pulse advance/query basket is excluded: its opaque stop word could not share the original byte view and silently defaulted to zero. Complete movement, terrain/hazard decision, damage effects allocation, protection/drain, history indices/callbacks and checkpoint/terminal scenes remain specific open dependencies.

This round used one narrow static lift attempt and actual pure Composer graph validation. It performed no ROM/game generation, Ghidra export, manual-C compiler input, native campaign or broad rerun. The existing finite qualifications are retained separately and do not certify a full prefab runtime.
