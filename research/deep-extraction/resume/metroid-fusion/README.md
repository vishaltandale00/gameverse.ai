`08000a2c` computes held, pressed and previous input in that order. The original table at `0828fd58` maps state 0 to Thumb target `08006591`; `080063f8` dispatches through it. Under state 0, no override, no alternate ledge branch and a new A edge without held down, `08006590 → 08005f60` sets jump variant 1 and returns request `fe`. `08008fa0` handles `fe`, but its binding to that returned request remains an unresolved scheduler edge. It calls `08004d60`, which copies the current 44-byte player state to a distinct previous-transition snapshot and then clears/masks current transients. Its `fe` branch calls `08009080`, which reads the saved variant and initializes ordinary airborne state 4 with vertical speed `aa` or `dc`, selected by ability bit 0 at `0300131c`.

`08009d78` integrates airborne vertical position using the signed clamped speed shifted by three, then subtracts gravity from the speed when above the terminal comparison. Its scheduling after transition remains unverified. Positive vertical speed decreases native Y. Terrain shifts by six establish 64 coordinate units per tile; pixel scale and game-frame timing are not qualified. Collision/landing through `0800a054` is the next closure boundary.

Preserve a single packed backing for current state: word `03001244` aliases state/variant bytes; word `0300125c` aliases Y and horizontal speed; word `03001260` aliases vertical speed and the next halfword. The snapshot is a historical copy, not another independent live player. Copy-before-clear and byte/halfword/word store order are mechanically observable. Input, world-map references, dynamic dispatch and audio events need explicit services; audio optionality has not been demonstrated.

The first compiler blocker is concrete: cached HighFunction models normal stack-restored returns as `CALLIND`. At `08005f58`, ROM bytes `70bc02bc0847` decode as `pop {r4,r5,r6}; pop {r1}; bx r1`; L0 `08005eec` has an apparent indirect call at `08005f5c`. Likewise `10bc01bc0047` at `08009076` is `pop {r4}; pop {r0}; bx r0`. These should be distinguished from real game callbacks with return-value ABI recovery, rather than assigned an invented external service.

Priorities are: (0) return/ABI and actual driver/dispatch owner; (1) jump gate, snapshot and transition; (2) integration and terrain classifier `08068b1c`; (3) alternate branch/support helpers; (4) full collision/landing.
