# Wario admission coverage

Four published protection-query packages passed the real generic assembly/Composer binding and lowering path: `binding_valid_obligations_unproven`, four invocations, 0.010895 seconds. Exact graph, package/behavior hashes and receipt are pinned in `manifest.json` and `source-contract.json`.

Two predicates read the same externally owned protection counter and write separately owned results. The read/tag helpers share a separate externally owned query-bitset input. Opaque selectors stay private at zero/default, with the validator warnings retained. The declared order is a caller query schedule, not a recovered controller chain. No unit scaling, inferred alias or return capture was added.

A hurt → recovery → aging sequence cannot be admitted from these four packages: those transition roots are not published, the four return meanings are unavailable to the assembler, and predicate-result versus raw-bitset semantics cannot be bridged without additional source-backed contracts. Full hazard callbacks, terrain and presentation/resource services remain open. The initial counter96 is a source-observed recovery sample only; this graph neither performs recovery nor decrements the counter.

This proves symbolic package identity, ownership, binding and actual code lowering. It does not prove runtime reachability, complete lifecycle or composed native parity. No mining, exports, native tests, game builds or ROMs were performed.
