Static evidence maps one concrete mechanic: turn initialization → shared item roll → pairwise priority/effective-speed comparison → conditional tie RNG → paired action/battler-order swap → next action callback. This is a dependency closure proposal, not an executable component or complete battle implementation. All games remain partial; Mario retains depth priority.

The comparator is `0x0803cf10`, scheduler `0x0803d2e8`, paired swap `0x0803cedc`, and main RNG `0x0806f5cc`. Effective speed applies weather/ability multiplier and stage ratio, badge multiplier, half-speed item, paralysis, and shared-roll override in that order. Signed move priority is compared first. Equal speed and priority consume the main RNG conditionally; the scheduler swaps on nonzero comparator result. A generic sorting algorithm with a different comparator call order would change RNG consumption.

Keep the `0x58` battler records as one shared collection. Order positions and battler IDs are distinct. Both parallel order lanes must move together. Keep the per-turn roll at `0x02024330` shared across both battlers and all comparisons, and preserve the global RNG state/counter pair. The threshold is a strict integer comparison against `floor(parameter*65535/100)`. Physical layouts are validation evidence; a later executable component needs symbolic owned state and alias-preserving references.
