# SOUL LOOM

SOUL LOOM consumes the newly qualified automatic L1 `aria.progress.category3_acquire` in an authored packed-inventory balancing interaction. It replaces Life Relay's death/life/Minish progression path. The world, controller, projectiles and presentation remain the existing authored clean-ROM substrate. Automatic L2 recovery and original Aria cast/pickup/equip/save behavior remain open.

The recovered component receives category exactly 3, constant index 0 or 1, and explicit quantity adjustments through its real ABI. Its one canonical `u8[4]` collection is bound directly to L2 `soul_bank`, with quantity `packed_four_bit_inventory` and frame `inventory.soul.category3`. Both original source banks alias this same bank; no independent bank or shadow inventory is introduced.

The authored pickup invokes index 0 with quantity +4. Controls then invoke the same recovered behavior. The actual canonical byte follows `00 → 04 → 05 → 05 → 04 → 14`: successful acquisition, charge, a second charge exercising source capacity/alias rollback, signed spend, and neighboring upper-nibble acquisition. The gate reads actual decoded low/high nibbles and opens only for low 4/high 1. Acquisition alone and the wrong balance 5 leave it closed. This is the source's exact category-three behavior; no generic aggregate-count ≤9 invariant is claimed. The rollback demonstration is tested but is not a prerequisite for winning: UP immediately after the initial pickup also produces the target balance.

Keyboard controls: arrows move, **X** jumps, **Z** fires. After collecting the pickup, **S** sends the GBA **R shoulder** to charge; **DOWN** spends one; **UP** adds to the neighboring slot. Release between actions. Holding UP does not repeat because transaction scheduling uses authored button edges. Gamepad controls use A jump, B fire and right shoulder charge. Keyboard letter A is the other shoulder, not jump.
