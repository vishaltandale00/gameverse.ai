# Original FireRed credits in the single native engine

`tools/whole_game/single_rom/credits.py` exposes `stage_credits(base, donor, out, report_dir=None)`. Run it after progression, exact donor fonts, native UI and shared Quest Log state, before the native-special provider inventory. It edits only the isolated source snapshot and preserves earlier workers' patches.

The shared Emerald Hall of Fame screen, its saved team history and `gHasHallOfFameRecords` remain intentional shared engine services. The screen's exit checks `WholeGame_IsKanto()`. Hoenn retains `CB2_StartCreditsSequence`. Kanto executes the original FireRed `SetWarpsToRollCredits`: set the Indigo exterior scene variable, suppress map labels, keep music, warp to Indigo Plateau exterior at (11, 6), and reset the avatar state. The imported original Indigo script performs its timed rival/Oak/player movements, plays `FR_MUS_CREDITS`, resets the scene variable and invokes `FR_special DoCredits`. The source macro resolves that call through the native special registry to `FR_DoCredits`.

The port retains all 16 original credits functions, original command sequence, staff ordering/text, window timings, affine Pokémon scenes, player/rival/ground animation, copyright screen, final screen and original `SoftReset(RESET_ALL)` termination. Nine original overworld helpers retain the map-load, scroll, palette, callback and task states. The actual source camera update intentionally omits normal actor refreshes, as FireRed does. Original selected-palette weather fades retain their palette masks. Source KEEP/STOP music guards prevent normal map tracks and ambient cries from interrupting the ending; OFF preserves the native path.

All 14 referenced maps use `MAP_FR_*` constants. The stage imports 40 editable original PNG/palette/tilemap sources. Four original FireRed Pokémon front pictures and their normal/shiny palettes are included separately, so the composite credits images do not silently use Emerald artwork. The private picture pipeline is copied from FireRed and is reachable only for Charizard, Venusaur, Blastoise and Pikachu with the original front-picture/OT/personality inputs. Existing source fonts `FR_FONT_NORMAL` and `FR_FONT_NORMAL_COPY_1` supply the original glyphs. Quest Log owns the shared field-tint and music-disable variables; this stage does not duplicate their storage.

`credits-ledger.json` records source/art pins, the callback chain, provider registry shape and source outputs. Its source eligibility is true with no missing providers in the isolated prepared snapshot. `assets-witness.json` pins 48 existing original converted resources and verifies their editable source bytes against the canonical donor; the raw source remains editable and is imported for normal build conversion. Reusing these conversions avoids an unnecessary asset rebuild during the focused compiler check.

Three focused source checks pass in 0.977 seconds. All five affected C translation units compile with the actual `agbcc` cartridge compiler, including `-Wimplicit -Wparentheses -Werror`, and assemble with `arm-none-eabi-as`. Aggregate targeted compilation took 0.585 seconds; assembly took 0.050 seconds. These are aggregate sequential source-check times, not a full ROM build. Initial failed compiler/preprocessor attempts are retained in `target-verification.json`; missing declarations and isolated asset/header setup were corrected. There is no before/after baseline for this new stage. No full build, linked cartridge ending, player-driven ending sequence or continue/load recovery was executed by this worker. Progression owns the saved clear/Pallet-respawn behavior; the integrated build and native ending route remain separate qualification.
