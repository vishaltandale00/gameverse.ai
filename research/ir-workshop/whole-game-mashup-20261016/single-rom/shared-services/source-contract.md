# Shared native service source contracts

The stage `stage_shared_services(base, donor, output, report_dir)` audits every FireRed script native dependency against the pinned source trees. It emits a real C wrapper only after an exact public signature and body match, audited shared state and helper effects, and numeric ID checks. Unknown, divergent, or unowned functions receive no binding. Its JSON ledger includes each accepted/rejected root, source hashes, contract evidence, and provider rows for `native_services`.

With the staged shared bag increased to 42 item slots, nine of the frozen 145 missing reachable roots have accepted wrappers: `CalculatePlayerPartyCount`, `GetPlayerFacingDirection`, `GetTrainerBattleMode`, `IsEnoughForCostInVar0x8005`, `LoadPlayerBag`, `LoadPlayerParty`, `SavePlayerParty`, `Script_FadeOutMapMusic`, and `SubtractMoneyFromVar0x8005`. `LoadPlayerBag` is conditional on **all** staged pocket and mail capacities meeting or exceeding the donor values (42/30/13/58/43/16); the Emerald staged values tested were 42/30/16/64/46/16. If the item expansion is absent, the stage emits eight wrappers and leaves `FR_LoadPlayerBag` unresolved.

`HealPlayerParty` is a separate compatible capability currently supplied by `campaign_services`, so the resolver does not emit a duplicate. The donor and host public bodies match. The touched `GetMonData3` MAX_HP, `GetBoxMonData3` PP_BONUSES and MOVE1–MOVE4, `SetMonData` HP and STATUS, and `SetBoxMonData` PP1–PP4 source cases match. Relevant MON_DATA values and MAX_MON_MOVES=4 match, as does `CalculatePPWithBonus`. This is a bounded field-domain claim under the selected shared native Pokemon layout, not whole-function equivalence for the differing setters.

The isolated nine-wrapper fixture passed Emerald `clang -E`, `agbcc`, and `arm-none-eabi-as`; `arm-none-eabi-nm -g` showed all nine globally visible `FR_*` definitions. This proves syntax and assembler visibility, not final ROM link or gameplay. Five focused shared/world service tests passed in 4.570 s, including an induced staged-host drift rejection; the source audit/stage took 2.226 s on this machine. There is no before/after full-build timing for this stage yet. The frozen frontier had 145 missing reachable roots; the nine accepted roots are all within it. Residual roots remain assigned to source-family owners or unresolved.

The helper rejects same-name source drift (including changes in the staged host tree), out-of-contract globals/calls, regional FLAG/VAR/MAP references, numeric Pokemon ID drift, incomplete bag capacity, and existing staged `FR_*` definitions. It intentionally does not alias FireRed Easy Chat, in-game trade, link callbacks, or object-event/QuestLog helper paths without typed evidence or a source port. Its 262 rejected dependencies include roots already supplied by other stages; the frozen missing-reachable subset is the relevant link frontier. Exact accepted function/case hashes are recorded in `source-proof.json`, from an isolated capacity-42 fixture.
