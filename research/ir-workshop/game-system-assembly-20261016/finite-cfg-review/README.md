# Finite CFG source review

Scoped source-semantic clearance for the pinned optional `acyclic_basic_blocks/0.1` implementation and the current Driv3r allocator / Tekken separator roots. No blocking finding in this scope. This permits bounded native qualification by the target owners; it does not establish native parity, a whole recovered system, or new-game qualification. Exact source and root hashes are in `review.json`.

- `lift.py` emits each source block once. Branch and switch edges evaluate their selected predecessor-specific phi inputs into distinct temporaries before assigning any phi destination, then jump. Loads remain snapshots at their original block operation positions; stores and calls retain source order. Basic-flow block bodies skip phi entry reassignment because the incoming edge already performed it.
- `contract.py` validates symbolic label spelling, unique labels, present start and resolved jump targets. Iterative DFS checks cycles and requires all blocks reachable from the declared start. Each path must terminate through jump, return or an enclosing invocation-scope exit. Per-graph limits remain 4096 blocks and 4096 recursively counted statements. The existing lift expansion budget remains unchanged. Unreachable trailing statements are rejected.
- `lower.py` shares a monotonic label counter across recursion and namespaces each graph independently. Its initial goto enters the declared start; all emitted block paths terminate. Scope exits target the nearest dependency invocation, while graph jumps target only the active graph. Symbolic labels do not carry machine addresses.
- `inline.py` descends through graph block bodies for call expansion, while its generic dictionary/list rewrite descends into imported graph blocks to rename locals and rewrite return values to result assignment plus scope exit. Independent basic-flow callee graphs inside a basic-flow caller remain intentionally unsupported: the validator rejects them, as confirmed by the compiler owner. Neither current target root contains calls/scopes, so this limitation does not block these roots.
- Composer delegates package implementation emission to `lower(x)`; it does not need a second L1 block walker. Publication effect analysis recursively visits dictionary values and lists, so graph-contained reads/writes remain visible.
