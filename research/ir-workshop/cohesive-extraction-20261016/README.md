* **FireRed source animation prefab:** the [source-backed capsule](../../../local/ir/cohesive-extraction-20261016/presentation/capsule.json) identifies the reusable `source_prefab.h`/`.c` API, literal source animation bodies, four south/east idle/walk clips, nine RedNormal image cells, and exact player palette. Create one state instance, select a clip, pause/resume and tick to obtain frame/flip output. The 64-tick source-C scenario and API smoke test pass. Native frame copying, OAM/VRAM, palette loading, world anchors and actual game cadence are outside this portable selected-clip API. This is source-C execution, not HighFunction L1 or original-ROM parity.
* **Aria cast availability:** new automatically lifted `aria.cast.first_free_slot` returns the first free slot or `0xffffffff` from the original eight-slot pool. Its 256 original/emitted vectors include explicit read-only first-free/full-pool cases. It does not reserve the slot. Existing acquisition/count/enable-disable phases share campaign ownership state, while equip/descriptor/cast allocation/MP/retirement remain distinct open edges.
* **Kirby terrain occupancy and surface support:** the actual dynamic `08021ab4` source sampler now passes **7,456 original/emitted comparisons** under a one-cell map and local X/Y in `0..15`. All 256 source shape selectors are covered, including every local offset for each of the 14 distinct occupancy rows. It returns signed occupancy without publishing probe scratch. Six new displacement specializations also cover shape selectors 2 and 3 on three axes, each with 256 original/emitted comparisons, joining the three existing shape-1 members. These remain phases of one terrain system. The packet records actor-to-scratch setup, publishing/below-cell samplers, correction and same-actor commit as remaining dependencies; qualified source-cell sampling is not a complete actor landing controller.
* **Dragon Ball input phase:** the existing source edge/repeat member was executed in a bounded host scenario distinguishing a fresh press, continued hold and source suppression. A newly lifted initializer passes 256 original/emitted vectors, but its four cleared fields have unknown semantics, so it stays private. Physical/replay selection and the active controller callback remain open; this does not fix held-based repeat attacks by itself.
